# Operation

## Broadcast Deck

- **Music transport** (Play / Pause / Prev / Next) changes the program.
  Pause while on air holds silence on the carrier; it does not end RF.
- **Raise the Black Flag** starts the program **and** the FM transmitter.
- **Lower the Black Flag / STOP BROADCAST** ends transmission immediately
  (including STARTING / FAULT / UNKNOWN). Use it freely.

## Daily flow

1. Choose playlist / upload music (Music)
2. Set frequency and RDS (Station)
3. Confirm OFF AIR readiness (Broadcast)
4. Raise the Black Flag only when intentional and lawful
5. Lower the Black Flag when finished

Ship’s Log shows operator-meaningful events. System → Diagnostics holds
engineering detail.
