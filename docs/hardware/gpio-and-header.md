# GPIO and header

See the canonical hardware manual: **[../HARDWARE.md](../HARDWARE.md)**.

Quick reference for PiFmRds / piFM:

| Function | BCM | Header pin |
|----------|-----|------------|
| FM RF clock out | **4** | **7** |
| Optional status LED | 18 | 12 |
| Optional shutdown switch | 5 | 29 |
| Ground | GND | multiple |
